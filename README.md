# PowerShell Audio Downloader

Універсальний PowerShell-скрипт для завантаження аудіодоріжок з різних сервісів з можливістю ручного або автоматичного визначення метаданих.

## Можливості

-   Завантаження аудіо у форматі `.m4a`.
-   Автоматичне вбудовування обкладинки відео.
-   **Гнучкі метадані:**
    -   **Автоматичний режим:** сам визначає назву треку (з назви відео) та виконавця (з назви каналу).
    -   **Ручний режим:** дозволяє вказати власні назву та виконавця.
    -   **Гібридний режим:** можна вказати лише один параметр (наприклад, назву), а інший скрипт визначить автоматично.
-   Надійна обробка помилок та гарантоване видалення тимчасових файлів.
-   Збереження фінального файлу на Робочий стіл.
-   Підтримка глобального виклику (після додавання у `PATH`).

## Вимоги

1.  **yt-dlp**
2.  **ffmpeg**

Найпростіший спосіб встановити та оновлювати їх — через `winget`:
`winget install yt-dlp/yt-dlp`
`winget install Gyan.FFmpeg`

## Використання

Скрипт можна викликати з будь-якого місця в терміналі (після налаштування `PATH`), передаючи йому параметри.
Без `PATH` потрібно викликати у папці з файлом (`cd ...\Audio-Script-with-metadata`*) з параметром `.\`.
_* - папка, де міститься `mdown.ps1`._

### Повністю автоматичний режим
Достатньо вказати лише посилання.
```powershell
mdown.ps1 "URL"
```

### Ручний режим
Вкажи власні назву та виконавця.
```powershell
mdown.ps1 "URL" "Моя Назва" "Мій Виконавець"
```

### Гібридний режим
Вказати лише назву (виконавець автоматично):
```powershell
mdown.ps1 "URL" "Моя Назва"
```
Вказати лише виконавця (назва автоматично):
*Зверни увагу на порожні лапки "" як заповнювач для назви.*
```powershell
mdown.ps1 "URL" "" "Мій Виконавець"
```
